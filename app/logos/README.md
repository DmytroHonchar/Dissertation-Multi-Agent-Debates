identify which model each agent is; they are trademarks of their owners and
imply no endorsement.

Source: `@lobehub/icons-static-svg` version 1.95.1 (MIT licence), downloaded
from `https://unpkg.com/@lobehub/icons-static-svg@1/icons/` on 2026-10-09.
The files are unchanged. Each contains only paths and gradients: no scripts
and no external references. They are embedded in the stage as inline images,
so the public app never fetches them from another site.
