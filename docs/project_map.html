Three "run" functions, three sizes: run_debate_question() = both rounds. run_round1_question() = one whole round. run_one_agent() = one agent's result. The real network request happens inside api_client.py.

Main rule: both rounds finish for one question before the next question starts. Agents run one by one. A box inside a line = called by the box above it.

Real example: question mmlu_pro_v1:test:5503. "When may an issue fail to become securitized?" 3 options. Correct answer: A.

Cache hit: skip the API request. Continue to parsing and saving.

API failure: run_one_agent() records API_ERROR and continues to the next agent. No model reply is parsed or cached for that failed request.

Never saved

  • The correct answer in the experiment database.
  • The API key.
  • Fake test replies in the cache.
  • Failed calls in the cache.
  • Any overwrite.

Grey text on a box = where the function is defined. Line numbers refer to the current files. They can move when the code is edited.
